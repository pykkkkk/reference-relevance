# 中文来源能力边界（诚实声明）

本 skill 面向经管学科，中文文献占比高，但可直接调用的能力有限。**本文件是硬约束，不得绕过。**

## 各来源实际能力

| 来源 | 能否自动检索 | 说明 |
|---|---|---|
| CNKI 知网 | 否 | 无公开 API；不绕过验证码与反爬。引导用户在官网检索后导出 RefWorks / EndNote 题录 |
| CNKI AI LINK | 否（经管） | 目前仅开放法律、医药卫生、基础教育、专利四个领域，不覆盖经管 |
| 万方数据 | 部分 | WorkBuddy 生态有万方连接器，支持主题/题名/作者检索与期刊、学位论文全文下载；按点计费，有试用额度 |
| 维普 | 部分 | WorkBuddy 生态有维普技能，中文期刊题录与部分全文，有月度免费额度 |
| 百度学术 / 掌桥科研 | 否 | 反爬与验证码；不作为权威来源 |
| OpenAlex / Crossref | 很弱 | 对中文经管核心期刊覆盖极差，命中的常是无关领域；不得作为中文臂主力 |

## 推荐工作流

1. 用户已在 CNKI / 万方检索 → 导出 **RefWorks 或 EndNote** 题录文件 → 本地解析（可与英文结果合并去重）。
2. 未检索 → 引导用户在万方连接器或维普技能中检索；若无连接器，明确告知需人工导出题录。
3. 题录解析后按 **作者 + 题名 + 年份 + 刊名** 四字段与正文引用比对；缺字段记 `partial_match`。

## 降级话术（必须照用）

- 查不到：**「无法核验：该中文文献不在当前可接入的数据库中，请人工核对原文。」**
- 禁止输出：「文献不存在」「该引用是伪造的」。
- 题录不全：**「题录字段不完整，仅能部分比对。」**
- 摘要不可得：**「中文来源未提供摘要，仅做题名级判断，置信度受限。」**

## 禁止事项

- 不绕过验证码、滑块、IP 限制。
- 不把网页关键词命中当作文献存在性证据。
- 不把 OpenAlex / Crossref 的中文漏检解释为文献不存在。
- 不在未告知用户的情况下把未发表稿件上传到第三方服务。

## 对判定的影响

- `verification = unverifiable_zh` 的文献：不得判 D 级，不得作为「应替换」的直接依据。
- 若该引用的需求本身明确且正文表述有问题，可建议 `rewrite_text`，并注明「中文文献未能核验，建议作者自行确认」。

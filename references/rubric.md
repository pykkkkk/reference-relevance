# 相关性评分量规 v0.2

## 用途

评估「正文引用需求 ↔ 已引文献供给」的对齐程度。评估与替换候选重排使用**同一套量规**，不得为检索另建一套标准。

## 输入

- `needs.json`：每个论断单元的功能、强度、必要程度、结构特征、置信度
- `supply.json`：每篇文献的真实摘要/元数据、证据类型、样本/任务、时效、结论方向、来源层级、可核验性

## 证据等级（决定能下到什么结论）

| 等级 | 可得证据 | 置信度上限 | 允许判定 |
|---|---|---|---|
| `full_text` | 全文证据句 | 1.0 | A / B / C / D |
| `abstract_only` | 题目 + 真实摘要（API 额度不足时的**默认降级模式**） | **0.6** | A / B / C；**不得直接判 D** |
| `title_only` | 仅题录，无摘要 | **0.45** | 只做主题/功能初判，强制 `abstain: true`，不判支撑性 |
| `unverifiable` | 无可核验来源 | 0.3 | 不做判定；中文来源按 `cn-sources.md` 话术输出「无法核验」 |

**降级规则（硬性）**：
- API 返回 429 / 预算耗尽 / 强制 `--abstract-only` 时，`fetch_metadata.py` 自动进入降级模式。
- 摘要级证据不得直接给出 D 级；最多判 C（弱相关需人工）。若正文与题名/摘要明显冲突，输出 `suspected_mismatch: true` + 建议人工读全文，而不是 D。
- D 级（错配/替换）必须来自全文证据句或作者人工确认。
- 降级模式下不得自动触发替换候选的写回；候选仍可检索，但标 `evidence_level: abstract_only`。

## 评分维度与权重

| 组 | 维度 | 权重 | 1.0 锚点 |
|---|---|---|---|
| 需求对齐 | 功能匹配 | 0.25 | 文献直接提供该需求类型（如方法来源给出所用计量策略的原始文献） |
| 需求对齐 | 对象匹配 | 0.15 | 样本、任务、制度情境、研究对象完全匹配 |
| 支撑性 | 命题支持 | 0.30 | 原子化论断被文献证据句直接蕴含 |
| 支撑性 | 方向性 | 0.10 | 结论方向对该论断为支持；中性提及计 0.3；反驳触发一票否决 |
| 供给质量 | 证据强度 | 0.10 | 因果识别设计 > 高质量观察性数据 > 案例/理论推导（按学科调整） |
| 供给质量 | 时效与版本 | 0.05 | 版本正确且不过时；经典理论奠基文献豁免时效 |
| 供给质量 | 一手性与可核验性 | 0.05 | 一手来源且摘要/全文可得，证据句可定位 |

加权总分 = Σ(维度分 × 权重)。

## 逐维度判定要点

**功能匹配**
- 1.0：直接提供所需功能（理论依据、测量工具、识别策略等）
- 0.7：同类功能但间接（同理论传统、同类数据集）
- 0.4：仅提供背景，不能承担该论断的支撑
- 0.1：功能完全不匹配（如用综述支撑具体数值）

**命题支持**
- 先把论断拆成原子 claim，逐条判断；一条不被支持即不得给满分
- 1.0：直接蕴含且数值/结论一致
- 0.7：需一次合理推断，无矛盾
- 0.4：仅主题相关，无直接证据
- 0.0：矛盾或找不到任何证据句
- 建模模板跳过本维度，改判「模型/假设/方法来源是否匹配」，并强制人工确认

**方向性（一票否决）**
- REFUTE（反驳）：总分无效，直接判 D，不得作为支持性供给
- NEUTRAL（中性提及）：方向性计 0.3，且命题支持不得高于 0.4
- SUPPORT：方向性计 1.0

**证据强度（经管口径）**
- 因果识别设计（RCT / DID / IV / RD / PSM）> 大样本面板 / 准实验 > 案例与描述统计 > 纯理论推导
- 经典理论文献（如代理理论、资源基础观）不因年份早而扣分
- 数据来源权威性（CSMAR / Wind / 官方统计年鉴）单独作为子项

**装饰性引用检验（ALCE citation precision 思路）**
- 若删除该引用后，其余引用仍能支撑该论断，则标记 `decorative: true`
- 装饰性引用即使总分不低，也应降级为 C 并给出「删引或改正文」建议

## 分级

| 级别 | 条件 | 建议动作 |
|---|---|---|
| A 直接支持 | 总分 ≥ 0.85，无否决，无 decorative | keep |
| B 背景可用 | 0.65 ≤ 总分 < 0.85，无否决 | keep（可提示增强证据） |
| C 弱相关需人工 | 0.40 ≤ 总分 < 0.65，或 decorative | rewrite_text / add_citation / replace_citation |
| D 错配 | 总分 < 0.40，或方向性为 REFUTE，**且证据等级为 `full_text` 或经人工确认** | replace_citation / remove_citation |

> 降级模式下总分即使 < 0.40，也只输出 C + `suspected_mismatch: true`，并建议人工读全文；不得判 D。

## 证据与置信度

- 每条判定必须附：正文论断、引用处上下文、文献证据句（摘要或全文原句）、逐维度分数、理由、**证据等级**。
- 摘要不可得时标注 `title_only`，仅做题名级判断，置信度上限 0.45，强制转人工。
- 中文文献无法核验时标注 `unverifiable_zh`，不做 D 级判定，输出「无法核验」。
- 置信度阈值：≥ 0.8 直接采用（仅限 `full_text`）；0.6–0.8 抽检；< 0.6 强制 `abstain: true` 转人工。`abstract_only` 上限 0.6，`title_only` 上限 0.45。

# 引用功能分类体系（经管实证 / 建模）

## 目的

把「正文此处为什么要引用」结构化为需求画像。先判正文，再看文献；不得反过来从文献主题倒推需求。

## 两轴模型

**功能轴**（为什么引）：见下方两个模板。
**强度轴**：`直接证据` / `间接背景`。
**必要程度**：`必须引用` / `建议引用` / `常识性可免引`。

功能与强度正交：背景类引用可以是合理的（功能=背景共识、强度=间接背景），不应仅因分数低就判错配。

## 模板 A：econ-empirical（经管实证论文）

| 功能标签 | 判定线索（正文常见措辞） | 合格供给特征 |
|---|---|---|
| 理论/假说依据 | 「根据…理论」「基于…模型推演」「…提出假说」 | 原始理论文献或权威综述，而非二手转引 |
| 文献综述与研究缺口 | 「已有研究表明…」「然而较少关注…」 | 同主题实证文献，覆盖有代表性 |
| 数据/测量来源 | 「数据来自 CSMAR / Wind / 统计年鉴」「参照…量表」 | 数据库官方说明、量表原始文献或权威版本 |
| 变量定义/指标构建 | 「参照…的做法度量」「采用…指数」 | 指标或方法的原始文献 |
| 计量识别策略 | 「采用 DID / PSM / IV / 固定效应」「借鉴…的设计」 | 方法原始文献或该设计的经典应用 |
| 实证结果对比 | 「与…结论一致 / 不同」「高于…的估计值」 | 研究对象与识别策略可比的实证文献 |
| 政策/制度背景 | 「自…政策实施后」「制度背景见…」 | 官方文件或权威制度描述 |
| 方法/算法来源 | 建模与估计细节的具体出处 | 一手方法文献 |

## 模板 B：econ-modeling（经管建模论文）

| 功能标签 | 判定线索 | 合格供给特征 |
|---|---|---|
| 模型假设来源 | 「假设沿用…」「为简化起见参照…」 | 假设的原始文献或同类标准设定 |
| 定理/命题来源 | 「证明见…」「该结论由…给出」 | 定理原始文献，不可由摘要级相似替代 |
| 求解方法 | 「采用…算法求解」「参照…的均衡解法」 | 方法的原始文献 |
| 基准模型对比 | 「与…模型相比」「拓展了…框架」 | 被拓展的基准模型文献 |
| 参数校准/经验依据 | 「参数参照…校准」 | 数据来源或经验研究原始文献 |
| 文献综述与研究缺口 | 同实证模板 | 同实证模板 |

**建模模板硬性规则**：跳过 NLI 支撑性判定。摘要无法承载数学命题的「蕴含/反驳」关系，只能判断「来源是否匹配」，并强制人工确认。

## 与 SciCite 三类的粗映射

| 本体系 | SciCite |
|---|---|
| 文献综述、理论/假说依据、政策背景 | Background |
| 数据/测量、变量定义、识别策略、方法来源、求解方法 | Method |
| 实证结果对比、基准模型对比 | Result Comparison |

映射仅用于复用已有模型，不用于替代本体系：经管特有的「理论/假说依据」「数据/测量来源」在 SciCite 中被并入 Background/Method，会丢失决策所需信息。

## 多位引用

`[1,2,3]` 或 `(Smith, 2020; Jones, 2021)` 中，每位引用单独分配功能标签。常见组合：理论依据 + 方法来源 + 结果对比。不得整组共用一个需求判断。

## 判定纪律

- 一句含多个论断时拆开，分别归类。
- 常识性表述、数学推导、作者自述贡献不产生引用需求。
- 「综述」是供给形式，不是需求类型；不要把它填进功能轴。
- 低置信度一律 `needs_review: true`，不要强行归类。
